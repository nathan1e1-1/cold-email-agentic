# Delete / Trash — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move outreach threads to Gmail Trash from the reader, with a Trash view that restores them (Gmail auto-purges after 30 days).

**Architecture:** Gmail provider gains trash/untrash + an `inTrash` query; the mailbox adapter forwards them; the repository removes a thread's cards/messages/row; a new Trash view lists `in:trash` outreach threads. `gmail.modify` is added, with a forced reconnect path.

**Spec:** `docs/specs/2026-10-24-trash.md`

### Task 1 — API + data **[agent]**

**Files:** `src/mail/oauth.ts`, `tests/mail/oauth.test.ts`, `src/mail/mailProvider.ts`, `src/mail/gmailProvider.ts`, `src/services/mailbox.ts`, `src/services/gmailMailboxAdapter.ts`, `src/db/repository.ts`, `src/db/nodeRepository.ts`, `src/db/tauriRepository.ts`, `tests/mail/gmailProvider.test.ts`, `tests/services/gmailMailboxAdapter.test.ts`, `tests/db/repository.test.ts`

- [ ] `oauth.ts`: add `'https://www.googleapis.com/auth/gmail.modify'` to `DEFAULT_SCOPES`; assert it in `tests/mail/oauth.test.ts`.
- [ ] `mailProvider.ts`: add to `listThreads` opts `inTrash?: boolean`; add
```ts
trashThread(id: string): Promise<void>;
untrashThread(id: string): Promise<void>;
```
- [ ] `gmailProvider.ts`: base query (trash wins):
```ts
const base = opts.inTrash
  ? [`in:trash newer_than:${opts.sinceDays}d`]
  : opts.inInbox === false
    ? [`newer_than:${opts.sinceDays}d`, '-in:spam', '-in:trash']
    : [`in:inbox newer_than:${opts.sinceDays}d`];
```
and methods:
```ts
async trashThread(id: string): Promise<void> {
  ensureOk(await this.request('POST', `/threads/${encodeURIComponent(id)}/trash`), 'Gmail trash');
}
async untrashThread(id: string): Promise<void> {
  ensureOk(await this.request('POST', `/threads/${encodeURIComponent(id)}/untrash`), 'Gmail untrash');
}
```
- [ ] `mailbox.ts`: `ThreadQueryOptions.trashed?: boolean`; `MailboxProvider` gains the two methods.
- [ ] `gmailMailboxAdapter.ts`: forward the two methods; add `inTrash: opts?.trashed ?? false` to every outreach `provider.listThreads` call (single and overflow).
- [ ] `Repository` + both impls: `deleteThreadByProviderId(providerThreadId)` deletes drafts, cards, messages, then the thread row (look up the row id first; no-op if missing).
- [ ] Tests:
  - provider: `POST /threads/t1/trash`, `POST /threads/t1/untrash`; `inTrash` query contains `in:trash` and not `-in:trash`.
  - adapter: forwards the two calls; `listThreads({ outreachRecipients, trashed: true })` passes `inTrash: true`.
  - repository: seed thread + message + card, delete, assert all three are gone.

Verify: `npm test -- tests/mail/gmailProvider.test.ts tests/services/gmailMailboxAdapter.test.ts tests/db/repository.test.ts tests/mail/oauth.test.ts`, `npm run typecheck`.
